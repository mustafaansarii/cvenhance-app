# CVEnhance Backend

Welcome to the backend repository for **[CVEnhance](https://www.cvenhance.in/)**. 

CVEnhance is an intelligent resume builder and enhancement platform designed to help users create professional, optimized documents.

## Core Services & Features

This repository is built using a microservices architecture. The key features include:

* **Authentication Service**: Secure user login, registration, and session management.
* **AI Agent Service**: AI-driven resume enhancement, content suggestions, and analysis.
* **Document Service**: Create, compile (LaTeX/Native), and manage resumes and document templates.
* **Payment Service**: Integrated order processing and secure payment gateways.
* **Subscription Service**: Manage user entitlements, tiers, and subscription plans.
* **API Gateway**: Centralized API routing, security, and load balancing across all microservices.
